# Portfolio Website Agent Notes

## Source of truth

- Main editable content lives in `/home/ransu/codex-projects/portfolio-website/content/site-content.json`.
- React pages should render from that content instead of hardcoding duplicate copy.
- Machine-readable assets are generated by `/home/ransu/codex-projects/portfolio-website/scripts/generate-agent-files.mjs`.

## When editing content

1. Update `content/site-content.json`.
2. Run `pnpm run prebuild`.
3. If structure changed, run `pnpm build`.

## Routing

- Human pages are React routes.
- Markdown mirrors live in `public/*.md` and `public/projects/*.md`.
- `functions/[[path]].ts` handles `Accept: text/markdown` requests for Cloudflare Pages.

## Agent working docs

- Put agent-created plans, task lists, reference notes, and similar generated markdown files in `agent-generated-docs/` instead of the project root.
- Use `agent-generated-docs/` for working files generated by agents that support the project but are not primary source files.
- SCSS reference notes live at `agent-generated-docs/project-scss-reference.md`.
- Prefer clear descriptive filenames in `agent-generated-docs/` so the root stays focused on source files and primary project docs.

## Goal

Keep the site content-first, case-study oriented, and easy for both humans and agents to navigate.
