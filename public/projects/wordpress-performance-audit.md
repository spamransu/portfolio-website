# WordPress Performance Audit

- Year: 2025
- Client: Content Publisher
- Role: Frontend developer
- Stack: WordPress, PHP, SCSS, JavaScript
- Homepage image: https://example.com/images/home/featured-project-3.png

## Summary
A performance and UX cleanup effort for a content-heavy website.

## Challenge
The site suffered from heavy theme code, layout inconsistencies, and weak mobile navigation.

## Approach
- Removed dead styles and narrowed CSS to the components actually in use.
- Fixed responsive navigation behavior and simplified key templates.
- Prioritized readable content blocks and lighter page structure.

## Outcome
- Improved mobile experience and maintainability.
- Reduced styling debt in critical templates.
- Created a cleaner base for future content work.
