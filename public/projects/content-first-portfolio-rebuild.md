# Content-First Portfolio Rebuild

- Year: 2026
- Client: Personal Brand
- Role: Product designer + frontend developer
- Stack: React, TypeScript, SCSS, Cloudflare Pages

## Summary
A personal site rebuild focused on stronger project storytelling, clearer structure, and better machine readability.

## Challenge
The older portfolio showed visuals but not enough context, which made it harder for recruiters, collaborators, and AI tools to understand the work.

## Approach
- Shifted from gallery-style presentation to case-study style narratives.
- Created markdown mirrors, llms.txt resources, and structured metadata for machine access.
- Left room in the information architecture for a future writing section.

## Outcome
- Clearer project framing for hiring and client conversations.
- Better discoverability for both humans and agents.
- A maintainable base for future blog content.
