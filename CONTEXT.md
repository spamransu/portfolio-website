# Portfolio Positioning

This context defines the people, outcomes, and evidence that guide decisions about Lance Carteciano’s portfolio. It keeps the site focused on employment without excluding appropriate freelance work or general readers.

## Language

**Primary audience**:
A hiring manager or engineering lead evaluating Lance for frontend developer employment.
_Avoid_: Technical audience, recruiter audience, everyone

**Target role**:
A frontend developer role, supported by Lance’s WordPress implementation background and visual-design experience.
_Avoid_: Graphic designer role, WordPress-only role, full-stack role

**Primary outcome**:
A qualified job interview for a frontend developer role.
_Avoid_: Conversion, lead, engagement

**Visitor journey**:
The employment-first path from the homepage to selected work, then the resume and contact options.
_Avoid_: Freelance funnel, project inquiry funnel

**Case-study story**:
A concise account presented under four explicit headings: Problem, My responsibility, What I did, and Result.
_Avoid_: Technical write-up, project description, exhaustive breakdown

**Supporting detail**:
Optional implementation evidence that adds credibility without interrupting the plain-language case-study story.
_Avoid_: Main narrative, jargon dump

**Secondary outcome**:
A relevant freelance inquiry that does not displace the portfolio’s employment focus.
_Avoid_: Primary conversion, equal priority

**Accessible evidence**:
Concise, plain-language proof of the problem, Lance’s contribution, and the result, with optional technical detail where it strengthens credibility.
_Avoid_: Dumbed-down copy, technical deep dive, exhaustive explanation

**Credibility gap**:
Missing, weak, or hard-to-verify evidence that prevents a reader from confidently judging Lance’s work.
_Avoid_: Missing feature, polish issue

**Release scope**:
The smallest prioritized set of portfolio changes that materially improves its value for earning interviews.
_Avoid_: Backlog, redesign, general improvements

**Featured project**:
One of the four projects selected to lead the homepage evidence: Debase, ABCDE Creative Studio, Nsight Index, or the Portfolio CMS.
_Avoid_: WordPress maintenance system, every case study

**Evidence level**:
The basis for a result claim: measured evidence, an externally observable artifact or behavior, or a clearly qualitative practitioner outcome.
_Avoid_: Implied metric, unsupported impact
